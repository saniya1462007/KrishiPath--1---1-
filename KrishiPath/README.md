# KrishiPath

A frontend-only farmer procurement journey website.

## Run in VS Code

1. Open the `KrishiPath` folder in VS Code.
2. Open `index.html`.
3. Use VS Code Live Server (recommended) so browser geolocation and service-worker caching can work correctly.
4. Click **Start Journey**.

## Included

- English / Hindi language switch
- Farmer registration
- Browser GPS location
- Nearest procurement centre calculation
- Crop, quantity and quality selection
- Schedule and slot booking
- Digital token + QR-style token
- Live queue
- Dynamic ten-slot rolling buffer with 11th-slot movement
- Distance-based notification timing
- Offline-ready cached journey
- SMS notification status UI
- Procurement tracker
- QR confirmation interaction
- Responsive premium visual design

This project contains frontend logic only. It does not include a backend, database, real SMS gateway, or production payment/identity infrastructure.
